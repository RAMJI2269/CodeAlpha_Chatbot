# CodeAlpha Basic Chatbot

## About the Project

This is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Development Internship.

The chatbot accepts user messages and responds to predefined greetings, common questions, and goodbye messages.

## Features

* Responds to greetings such as hello, hi, and hey.
* Answers the question "How are you?"
* Displays a goodbye message when the user types "bye".
* Handles unknown messages.
* Uses a loop to continue the conversation.

## Technologies Used

* Python
* VS Code

## Python Concepts

* Functions
* If-elif-else statements
* While loop
* User input and output
* String methods

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python chatbot.py
```

## Sample Conversation

```text
Chatbot: Hello! Welcome to my chatbot.
Chatbot: Type 'bye' to exit.
You: hey
Chatbot: Hi!
You: how are you
Chatbot: I'm fine, thanks!
You: bye
Chatbot: Goodbye!
```
